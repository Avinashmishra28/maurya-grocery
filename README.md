# 🛒 Grocery Delivery App

A full-stack grocery delivery web application where users can browse products, manage their cart, place orders, and make secure payments using Stripe.

## 🚀 Features

### 👤 Customer

- User registration and login
- Browse grocery products
- Search products
- Filter products
- Product details
- Shopping cart
- Add, update, and remove cart items
- Address management
- Checkout
- Secure Stripe payment integration
- Order history
- Order tracking
- Flash deals

### 👨‍💼 Admin

- Admin authentication
- Admin dashboard
- Product management
- Add products
- Update products
- Manage product stock
- Order management
- Delivery partner management
- Assign orders to delivery partners
- View store statistics

### 🚴 Delivery Partner

- Delivery partner login
- View assigned deliveries
- View delivery details
- Update delivery status
- Update delivery location
- OTP verification
- Complete delivery
- Cancel delivery
